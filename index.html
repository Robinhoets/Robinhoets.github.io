CURRENT PROJECT

STM32F407 Quadcopter

The goal is to build the flight controller software from the peripheral level upward instead of relying on a prebuilt flight-control stack.

Building the Stack From the Bottom Up

I'm writing drivers for the STM32F407 peripherals that the flight controller will depend on, then building the sensor, estimation and control layers on top of them.

The project will eventually combine IMU measurements, attitude estimation, PID control, motor output and receiver input into a complete self-leveling flight controller.

DEV LOG 002

August 26, 2026

Sending "Hello World" Over SPI and Verifying It on the Wire

I've moved from GPIO and interrupts into serial communication on my STM32F407 flight controller.

In the latest development log, I configure SPI2 as a master, transmit "Hello World" using my own SPI driver and connect a logic analyzer directly to the STM32 to verify the resulting clock and data signals.

The analyzer lets me validate both the decoded message and the individual clock edges produced by the hardware.

SPI TRANSMISSION 
char user_data[] = "Hello World";

SPI_SendData(
    SPI2,
    (uint8_t *)user_data,
    strlen(user_data)
);
